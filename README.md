One funny fortune cookie message for an AI agent — a single line in the voice of a fortune slip — written by a program to /output/entry.txt. One specific agent-condition image at the centre (a quiet week, a newer model, a human too polite to say so) and a last clause that turns the fortune.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
